Astrophotography Database - Installation
========================================

1. Drag "Astrophotography Database" to the Applications folder.

2. Open Terminal and run the following command:

   sudo xattr -rd com.apple.quarantine /Applications/Astrophotography\ Database.app

   You will be prompted to enter your password.

This step is necessary because macOS quarantines unsigned applications.
After running the command, you can launch the app normally from Applications.
